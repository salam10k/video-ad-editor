# /blog

Run the `/write` skill (`.claude/skills/write/SKILL.md`) with the same arguments. Same steps, same checks.
To run it every morning like in the video, the user can schedule it (e.g. `/loop` or a scheduled routine): "Run /blog for <project> once a day; respect cadence."
