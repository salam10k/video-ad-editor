# وكيل SEO عام — يحلل، يصلّح، ويفحص

نفس طريقة فيديو
**Claude Code SEO Masterclass**،
بس يشتغل على **أي موقع أو متجر موجود** (Shopify، WordPress، سلة، زد، موقع مبرمج...) **وبأي لغة**.

كل مهمة تمشي بثلاث خطوات: **يحلل ← يصلّح ← يفحص.**

## الأوامر

| الأمر | وش يسوي |
|---|---|
| `/new-project` | يضيف مشروع جديد (يسألك كم سؤال) |
| `/audit` | يحلل الموقع: الصفحات، المشاكل، السرعة، الكلمات الناقصة، المنافسين → تقرير مرتب حسب الأهمية |
| `/fix` | يصلّح المشاكل في الموقع نفسه (أو يعطيك تعديلات جاهزة للنسخ) ثم يتأكد إنها انصلحت |
| `/check` | يفحص صفحة أو مسودة على 85 نقطة ويصلّحها |
| `/write` | يكتب مقال كامل بطريقة الفيديو، بلغة المشروع وأسلوب البراند |
| `/keywords` | يبحث عن الكلمات بأرقام حقيقية (OpenSEO أو Semrush) ويتأكد من نية البحث |
| `/tech-seo` | السرعة و Lighthouse وخريطة الموقع والبيانات المنظمة |

## مصادر البيانات

OpenSEO (الأفضل) · Semrush · Notion · Firecrawl · ملف الكلمات في المشروع. الوكيل ما يخترع أرقام أبداً.

## المشاريع

كل موقع له مجلد في `projects/`:
`project.json` (الرابط، المنصة، اللغة، السوق) · `brand.md` (الأسلوب والمعلومات المؤكدة فقط) · `keywords.csv` · `content/` (المسودات) · `reports/` (التقارير).

المشروع الأول: `projects/malfun/` — متجر MalFun (ألماني، Shopify)، بكلماته الحقيقية من OpenSEO عن طريق Notion.
