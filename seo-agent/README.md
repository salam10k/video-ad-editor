# وكيل SEO عام — يحلل، يصلّح، ويفحص

نفس طريقة فيديو
**Claude Code SEO Masterclass**،
بس يشتغل على **أي موقع أو متجر موجود** (Shopify، WordPress، سلة، زد، موقع مبرمج...) **وبأي لغة**.

كل مهمة تمشي بثلاث خطوات: **يحلل ← يصلّح ← يفحص.**

## خطوات الفيديو ← الأوامر

| خطوة الفيديو | الأمر |
|---|---|
| تجهيز المشروع | `/new-project` |
| 1. بناء الموقع (لو ما عندك موقع) | `/build-site` |
| 2. الكلمات المفتاحية الرابحة | `/keywords` |
| 3. أول مقال + كلمات قريبة + صور | `/blog` |
| 4. صوتك ونكتك وقصصك | `/voice` |
| 5. نسخ شكل أول 3 نتائج | داخل `/blog` |
| 6. صفحات الخدمات (أو الأقسام والمنتجات للمتاجر) | `/service` |
| 7. On-page SEO (أكثر من 80 نقطة) | `/check` |
| 8. Technical SEO و Lighthouse 100 | `/tech-seo` |
| 9. كل شي في أمر واحد | `/blog` |
| 10–11. النشر و Google Search Console | `/publish` |
| زيادة: تحليل موقع موجود | `/audit` |
| زيادة: تصليح المشاكل ثم الفحص | `/fix` |

## مصادر البيانات

الوكيل **يشتغل لحاله**: ملفات المشروع، والموقع نفسه، ونتائج قوقل الحية، و Semrush إذا موصول. ما يقرأ من OpenSEO ولا من Notion، وما يخترع أرقام أبداً.

## سجل العمل في Notion

بعد كل أمر، الوكيل يكتب سطر في **صفحته الخاصة** في Notion: التاريخ، والمشروع، والأمر، وش سوّى، والنتيجة، والخطوة الجاية. منفصلة تماماً عن صفحات OpenSEO.

## المشاريع

كل موقع له مجلد في `projects/`:
`project.json` (الرابط، المنصة، اللغة، السوق) · `brand.md` (الأسلوب والمعلومات المؤكدة فقط) · `keywords.csv` · `content/` (المسودات) · `reports/` (التقارير).

المشروع الأول: `projects/malfun/` — متجر MalFun (ألماني، Shopify)، بكلماته المفتاحية (منقولة مرة وحدة من خطة الكلمات الموجودة).
